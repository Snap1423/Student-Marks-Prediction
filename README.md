# Student-Marks-Prediction

📌 Overview

A simple machine learning model which predicts the students marks based on the number of hours studied.

🚀 Features

- Model training using Scikit-learn
- Visualization using graphs

🛠️ Tech Stack

- Python
- Pandas
- Scikit-learn
- Matplotlib

📊 Dataset

- Created a fake dataset which had two keypairs hours and marks.

📈 Model Used

 -Linear Regression
